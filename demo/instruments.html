Instruments

precision controls for data tools: rotary knobs, faders, bounded windows, segmented selectors, steppers. every value here is fixture data, wired to a readout and an event log on this page. wire the change events to your own state, never the reverse.

fixtures: every starting value below is a fixed number chosen for this page (a threshold, a date range, a page size). nothing on this page polls, streams, or fakes live data. see references/instruments.md for the full contract, including why input and change are wired to different things.

06 · init / destroy lifecycle

Inject, wire, and tear down

wonkControls.init(scope) wires instruments inside injected DOM (and scope itself, wiring a knob directly via wonk.knob() rather than calling the broader wonk.init(), which would re-wire unrelated legacy widgets). wonkControls.destroy(scope) clears each control's cached handle and removes the segmented selector's window-level resize listener before you discard the subtree.
