pair: metathesis
wonk / radio

Radio

a shuffle player for a public bucket of songs. one line of markup, no server. it lists the bucket in the browser, streams each file with range requests, and draws the real waveform while it plays. nothing plays until you press play.

01 · inline player

Live on gs://aktunes/music/

Shuffle plays every track once before any track repeats. Previous restarts the track after 3 seconds, else goes back one track.

live data: this player lists the real bucket when the page loads. if the list does not load, the status line says so and play retries it.

02 · dock

A fixed bar at the bottom of the page

Add wonk-radio--dock to the host. The page gets bottom padding while the dock is mounted, so no content hides under it.

03 · markup

One line

<link rel="stylesheet" href="assets/wonk-radio.css">
<script defer src="assets/wonk-radio.js"></script>

<section class="wonk-radio" data-wonk-radio data-bucket="aktunes" data-prefix="music/" aria-label="Radio"></section>

other sources: data-manifest="tracks.json" (a JSON array of URLs or {url, title, artist, number} objects), or wonkRadio.mount(el, {tracks}). data-title sets the station label.

05 · hosting

A public bucket is the whole backend

Make the bucket public for reads (allUsers as roles/storage.objectViewer). The player lists it with the JSON API and plays each file from its JSON API media URL. Those URLs send CORS headers, so the waveform works without a CORS config on the bucket. Files on other hosts need CORS for the waveform. Without it, the player falls back to plain playback and draws a flat line.

full contract, events, and checks: references/radio.md. run await wonkRadioChecks.run() in the console on this page.
